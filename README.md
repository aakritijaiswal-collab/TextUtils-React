# 📝 TextUtils

A modern and responsive **React.js** web application for analyzing and transforming text efficiently. TextUtils provides a collection of useful text utilities such as converting text case, removing extra spaces, copying text, counting words and characters, estimating reading time, and switching between multiple themes.

🌐 **Live Demo:** https://aakritijaiswal-collab.github.io/TextUtils-React/

---

## 🚀 Features

* 🔠 Convert text to **UPPERCASE**
* 🔡 Convert text to **lowercase**
* 🧹 Remove extra spaces
* 📋 Copy text to clipboard
* 🗑️ Clear text instantly
* 📊 Word Counter
* 🔢 Character Counter
* ⏱️ Reading Time Estimation
* 👀 Live Text Preview
* 🌙 Light & Dark Mode
* 🎨 Multiple Theme Colors
* 📱 Fully Responsive Design
* 🛣️ Multi-page Navigation using React Router

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/aakritijaiswal-collab/TextUtils-React.git
```

Navigate to the project folder:

```bash
cd TextUtils-React
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will be available at:

```text
http://localhost:3000
```
